01 — THE JOURNEY

Un viaggio.
Tre atmosfere.

Due versioni del viaggio

Le modifiche su questo dispositivo non coincidono con quelle presenti su Firebase. Nessuna versione verrà cancellata finché non scegli. Puoi prima esportare un backup JSON.

Importante: GitHub Pages ospita soltanto i file statici: la sincronizzazione cloud avviene attraverso Firebase Realtime Database, esclusivamente dopo Google Login e solo con i permessi concessi dalle regole Firebase. Se l’account non è autorizzato o sei offline, funziona la copia locale. I link/JSON includono anche eventuali codici di prenotazione: condividili privatamente.

Come funziona il salvataggio

Il budget, gli stati delle prenotazioni e le note sono memorizzati localmente. Per portarli su un altro dispositivo usa il backup JSON, la condivisione file o un link compresso. Non è sincronizzazione cloud in tempo reale; un import richiede conferma e sostituisce i dati locali. Le immagini e i font esterni richiedono Internet.
